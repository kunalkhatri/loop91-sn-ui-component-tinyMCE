# TinyMCE UI Component for ServiceNow UI Builder

A custom open source UI component that wraps the [TinyMCE](https://www.tiny.cloud/) rich text editor for seamless integration into the [ServiceNow UI Builder](https://developer.servicenow.com/dev.do#!/learn/learning-plans/tokyo/app_store_learnv2_uibuilder_tokyo_creating_experiences_with_ui_builder).

> 🚀 Enhance your ServiceNow experiences with a fully-featured, embeddable WYSIWYG editor.

---

## ✨ Features

- 🔗 Integrates TinyMCE into UI Builder with minimal configuration
- 🧩 Works as a standard UI component in the Now Experience framework
- 🎨 Fully customizable editor options
- 🔄 Two-way binding support for editor content
- 📦 Packaged as an open source, reusable component

---

Clone this repository and deploy it using the **Component Loader** in ServiceNow Studio or link it to your scoped application project.
